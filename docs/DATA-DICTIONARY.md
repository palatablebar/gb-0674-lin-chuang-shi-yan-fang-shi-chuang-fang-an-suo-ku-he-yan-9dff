# 访视与冻结定义

样例均为虚构编号，无身份信息。受试者入组日期由subjects表唯一确定，记录中的入组基准必须完全一致。采样日期和入组日期均转为Asia/Shanghai日历日期，差值为访视日；时刻先统一UTC。
方案选择按当前受试者assignment和该次发生时刻查半开生效窗，匹配必须唯一，不能使用全局最新方案。v1访视V1=[5,10)、V2=[12,17)；v2为[6,11)、[13,18)。受试者00001于10月10日转v2，其他受试者仍用v1。
PRIMARY计入访视完成，RETEST只替代该次测量值。首次记录必须唯一且在访视窗内。缺首次访视、重复首次和窗外访视均阻断，复检不能填补漏访或消除原偏离。
复检须引用同受试者同访视的PRIMARY，晚于原采样且不超过72小时，版本必须更高。同最高版本复检冲突时保留原结果并阻断。所有检验值以mg/dL输出，g/L乘100。
分析集在复检裁决之后、锁库检查之前定版，成员归属全部由上游证据派生，不接受人工改判。FAS全分析集以随机化为唯一门槛，随机后从未给药者仍保留，其随机与随访凭据可追踪；SS安全性集要求随机化后至少实际给药一次，方案偏离不剔除成员，只作为依据登记；PPS符合方案集要求已给药、主要终点访视V2可评估且无重大偏离（缺首次访视、重复首次、窗外访视、采信隔离），仅缺一次复检但主要终点完成者不剔除。首剂后退出者留在FAS与SS，主要终点不可评估则排除PPS。
成员版本按成员材料（每人三集入/出集结论、依据、阻断原因、给药次数）做SHA-256内容寻址，同指纹重试返回同一版本、不新增版本；上游处置更新使指纹变化时，旧版本在同一事务内标记superseded并另立新版，旧成员结论失效。整套替换在单个SQLite事务内完成，插入失败则回滚、保留旧版。锁库范围只能绑定status=current的成员版本，绑定后冻结印章纳入成员版本指针，归档包含analysis_membership.json。
锁库须所有规定访视完成，无偏离、复检问题和隔离行，且已锁定一个current成员版本。冻结包包含每条选定结果、原始行号、方案版本与访视窗。此工具只验证试验数据完整性，不做诊断判断或生产锁库。
